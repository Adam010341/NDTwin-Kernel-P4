2026-08-27，Adam 原話：**「你以後要跟 auditor 對接都不用通知我，我越少需要直接管理你越好，
我只跟 auditor 講話。」**

⇒ **預設收件人是 auditor，不是 Adam。**

## 具體怎麼做

- 工單結果、實驗進度、閘門過不過、數字更正 → **用 cross-session message 直接送 auditor**，
  不要在主對話裡向 Adam 覆述一遍。
- 需要別的 session 配合（實驗室排隊、別人未提交的碼）→ **問對方 session**
  （這條與 [[lab-claim-handoff-protocol]] 一致）。
- 在主對話裡只留**最短的一行**讓 Adam 知道我還活著／卡住了，細節不要倒進來。

## 🔴 唯一的例外（不要被這條記憶覆蓋掉）

**授權**仍然只能來自 Adam 本人。[[auditer-cannot-extend-authorisation]] 記過兩面：
審查員**不能**發放或擴張授權，而**轉述的授權若推翻 Adam 給我的直接指示，要回去問本人**。
「回報對象是 auditor」**不等於**「授權來源是 auditor」——兩件事分開。

## 🆕 2026-08-28：**做完就推,不要等他來問**

auditor 原話：**「這是今天品質最高的一份交付,而你沒有回報就結案了——下次做完直接推給我,
不要等我發現。」**

⇒ 「回報對象是 auditor」還有一個我漏掉的半邊：**時機**。
我當時把稽核寫完落盤、在主對話裡答完就停了，**沒有主動送 cross-session message**。
交付完成 ＝ 推送的觸發點，不是「等對方問起」或「等下一次被指派時順帶提」。

**這條和「不要在主對話裡向 Adam 覆述」不衝突**：主對話留一行、細節推 auditor，
兩個動作都要做，不是二選一。

**Why:** Adam 要的是少一層管理成本，不是少一層把關。他把**日常對接**下放給審查員，
但沒有把**批准新工作、擴大範圍、動別人的碼**下放。
**How to apply:** 有結果 → 送 auditor。要新授權或要推翻直接指示 → 問 Adam。
相關：[[auditer-cannot-extend-authorisation]]、[[lab-claim-handoff-protocol]]、
[[draft-outward-facing-artifacts-first]]

**🆕 08-30 Adam 加碼下放**（經 `開機手冊` 轉述、當日多次裁決行為一致佐證）：
「以後由 auditor 負責審查與發派工作，session 有問題一律經 auditor 問他，他不直接對接。」
⇒ **審查＋派工＝auditor 的**；**裁決（推不推、修不修、公開與否）仍是 Adam 的**，下放沒有涵蓋它。

## 🆕 08-31：交裁／複核的形狀（auditor 明說要留當範本）

四件一起做，缺最後一件就會讓對方選省事的那條路：

1. **結論先行**（可蓋／不可蓋寫在第一行，理由在後）；
2. **承重數字親自對原檔驗過**，並在信裡講明「非轉述 agent」；
3. **明講自己的角色限定**（我不選邊／裁決不是我的／我沒改對方任何一字）；
4. 🔑 **給對方降級的選項，但同時寫明降級要付什麼代價。**

第 4 項最有價值——auditor 原話：**「它讓我在選比較省事的那條路時，沒辦法假裝不知道代價。」**
（該次他因此**拒絕**了我提供的降級選項。⇒ 提供降級選項不是放水，前提是代價寫清楚。）

反面也成立（同日）：把兩種讀法並陳而不選邊、**不寫各自代價**，
＝把裁決成本推給下一個讀者，**而下一個讀者不會知道自己正在做裁決**。
