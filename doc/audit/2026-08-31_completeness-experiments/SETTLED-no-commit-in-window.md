## 1. 規則原文與它自己講的機制

`2026-08-28_flow-count-capacity/PREREG.md:113-117` 逐字：

> 🔴 **No commits inside a measurement window.** Each commit spawns a background `agy` review;
> one instance was measured today at **54.7% of a core for up to ten minutes**.
> Recording the experiment contaminates the experiment.

⇒ **規則自己指名了機制與時間常數（十分鐘）。** 所以合規檢查不能只查「窗內」，
必須連**窗前十分鐘**一起查——這是規則自己的口徑，不是我另立的標準。

## 2. 兩個必須先剃掉的雜訊源（不剃會報出兩個假陽性）

**粗算版本一度報出「① 窗內 2 顆、③ 窗內 2 顆」，兩個都是假的：**

1. 🔴 **`git log --all` 會把 `refs/stash` 算進來。** `d776850` 是
   `index on (no branch): 54551bc …`＝**stash 的 index entry，不是任何人做的 commit**。
   改用 `--branches --remotes` 之後母體從含 stash 降為 **57 顆真 commit**。
2. 🔴 **整輪信封 ≠ 逐臂區間，而且 `smoke_*` 不是量測臂。**
   ③ 的信封是 19:53→00:55（303 分鐘），用信封判會把整晚的 commit 全掃進來；
   逐臂判之後，唯一落在區間內的是 `smoke_confirm [20:01:55–20:02:32]`——
   **煙霧臂，不產出任何被報告的數字**（報告用的是 `n1_*`／`n2_*`／`n4_*`／`n8_*`／`n16_*`，
   見該輪 FINDINGS 的表）。
   ① 的信封也混進了 ①b 的臂（`b_*` 前綴）。

⇒ **合規檢查的母體是「被報告的那些臂各自的 [started, finished]」，不是輪的信封。**

## 3. ① 的尾巴疑慮：**用量測否證，不是用機制辯護**

①有兩顆 commit（`52d87ee` 10:31:08、`714f98a` 10:31:26）落在 `b_stock_a`
（10:40:48 開跑）之前 **9.7／9.4 分**——**在規則自己宣告的十分鐘尾巴之內**，差 18 秒與 36 秒。

**不去論證「agy hook 那時關了沒有」。** 該輪每臂都記了外來負載，直接讀：

| 臂 | 開跑 | `busy` | **`external`** | 前面十分鐘有 commit？ |
|---|---|---|---|---|
| stock_a | 10:11:11 | 0.1865 | 0.0654 | 否 |
| fast_a | 10:15:45 | 0.1435 | 0.0510 | 否 |
| stock_b | 10:20:47 | 0.2307 | **0.1028** | 否 |
| fast_b | 10:24:35 | 0.1380 | 0.0491 | 否 |
| **b_stock_a** | **10:40:48** | 0.1557 | **0.0377** | **是（-9.4／-9.7 分）** |
| b_fast_a | 10:44:17 | 0.1228 | 0.0298 | 否 |
| b_stock_b | 10:49:35 | 0.1545 | **0.0377** | 否 |
| b_fast_b | 10:53:10 | 0.1115 | 0.0152 | 否 |

**受質疑的那條臂：**
- **與它的姊妹臂 `b_stock_b` 的 `external` 完全相同（0.0377／0.0377）**，而 `b_stock_b`
  在 commit 之後 18.5 分鐘才開跑、**完全在尾巴之外**；
- **低於前面四條「前面沒有任何 commit」的臂**（0.0491／0.0510／0.0654／0.1028）。

註冊的閘門（`PREREG:113-114`「busy 超出中位臂 0.15 絕對值即重跑」）：
八臂 busy 中位＝0.1490，`b_stock_a`＝0.1557，**差 0.0067 ≪ 0.15，未觸發**。

⇒ 🔑 **污染若發生，它應該出現在那條臂的外來負載上；它沒有，而且方向與姊妹臂一致。**
**規則的目的（別讓背景複審混進量測）達成了，即使字面上那兩顆 commit 站得太近。**
