# FINDING — 兩條驗證線**同時往「看起來沒事」的方向**壞掉

**日期**：2026-08-31 · **提出**：遠端機器測試線 · **auditor 08-31 指示獨立成篇**
**狀態**：機制篇。**可轉移到任何「兩個檢查都說沒事」的場合**，與 git 無關

[Co-developed with claude code -- Adam]

---

## 一句話

**兩條獨立的檢查同時說「沒事」，通常被當成強證據。
這一次它們一致，是因為同一個錯誤把兩條都推向了同一邊。**

## 實例（逐字）

我要驗證「commit 推上去了沒有」。寫了兩條檢查：

```bash
git push -q origin HEAD 2>&1 | tail -3; echo "push rc=$?"
...
printf '  未推顆數: %s\n' "$(git log --oneline origin/rescue/detached-065889f..HEAD | wc -l)"
```

輸出：

```
Please make sure you have the correct access rights
and the repository exists.
push rc=0            ← 檢查一：說成功
  未推顆數: 0        ← 檢查二：說沒有東西沒推
```

**兩條都說沒事。而 push 是真的失敗的**（`rc=128`，`Permission ... denied`）。

| | 為什麼壞 | 為什麼壞向「沒事」 |
|---|---|---|
| 檢查一 | `$?` 取的是**管道最後一段** `tail` 的 rc，不是 `git push` 的 | `tail` **幾乎永遠成功** ⇒ 恆為 0 ⇒ 恆為「成功」 |
| 檢查二 | `origin/rescue/detached-065889f` **這個 ref 不存在** ⇒ `git log` 報錯、輸出零行 | `wc -l` 數的是**輸出行數** ⇒ 零行 ⇒ 「零顆未推」 |

## 為什麼這比單一檢查壞掉更危險

單一檢查壞掉時，我還會想「再看一眼別的」。
**兩條一致的時候，我停止了。** 一致本身被當成了證據。

> 🔑 **獨立的檢查會「同意」，可以是因為它們獨立地都對，也可以是因為它們共用了同一個失效方向。
> 而後者在輸出上與前者完全相同。**

這兩條檢查在**寫法上**確實獨立（一個看 rc、一個數 commit），
但它們共用一個**隱含的預設**：**「錯誤會讓數字變大或讓指令回非零」。**
實際上兩者的失效都讓數字**變成 0**，而 0 在這兩個語境裡都恰好是「好消息」。

## 病灶：兩個 idiom 的**沉默值**都落在「好」那一側

| idiom | 壞掉時的值 | 那個值的語意 |
|---|---|---|
| `cmd \| filter; $?` | filter 的 rc（通常 0） | 「成功」 |
| `<可能報錯的東西> \| wc -l` | 0 | 「沒有問題項」 |
| `grep -c <pattern>` 對錯的檔 | 0 | 「沒有出現」 |
| `find <不存在的路徑>` | 空 | 「沒有符合的」 |

⇒ **這一族的共同形狀：失敗與「乾淨」的觀測值相同。**
本 repo 既有的同族記錄：「刪除留下一個洞（大聲），改名留下一個假答案（安靜）」。

## 可轉移的判準（三題，都便宜）

1. **「這個檢查壞掉的時候會輸出什麼？」**
   若答案落在「好消息」那一側，它就**不是一個檢查**，是一個裝飾。
   ⇒ 每個回報「沒問題」的檢查，都要能被**強迫紅一次**（force-red）。
2. **「這兩條檢查若同時壞，會不會給出一致的答案？」**
   會 ⇒ 它們**不是**兩個獨立證據，是同一個證據講兩次。
   （同族：Agent 複審那份表裡**最危險的是「獨立路徑」那一欄**。）
3. **「rc 是誰的 rc？」** 有管道就先問這一題。
   `set -o pipefail`／`${PIPESTATUS[0]}`／**乾脆不要接管道**。

## 附帶：這次還有第二層（也值得記）

我把失敗讀成「push 權限壞了」，**而真正的原因是我推錯 remote**——
這條線的上游是 `lab/work/rescue-0831`，不是 `origin`。
`origin` 是一個**任何人都推不上去的上游**，而它剛好是不帶參數時最容易被打到的名字。

🔴 **同一個晚上，auditor 那條線獨立踩到了完全一樣的坑**，並且向 Adam 報告了
「push 被 GitHub 權限擋住」。**兩條線各自獨立命中 ⇒ 那不是個人失誤，是環境的形狀。**

⇒ 判準：**「我跑的那個對象，是這個宣稱在講的那個對象嗎？」**
一則真實的錯誤訊息，可以是對**錯誤問題**的正確回答。
