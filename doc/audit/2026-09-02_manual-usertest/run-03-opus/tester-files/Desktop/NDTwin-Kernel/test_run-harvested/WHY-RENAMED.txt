repo 根目錄的 .gitignore:21 有一條 `.test_run/`（註解寫「test-run artefacts

`Desktop/NDTwin-Kernel/.test_run/logs` 打包拉回來了，但

一個都沒有 ⇒ **那一輪的 kernel.log／ryu.log 從來沒進過版控，沒有人發現。**

本輪的 kernel.log 是 BUGS #14（`Command failed (exit code 7)`）與 NTG 時間線的

也避免 repo 裡出現一個看起來像活的 `.test_run/` 而被工具誤掃。
