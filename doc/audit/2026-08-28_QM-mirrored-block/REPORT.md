## 3. 工單 Q：修正成立，且**分母就是機制**

| 量 | base（2 臂均值） | Q（2 臂均值） | 差 |
|---|---|---|---|
| host→switch | 1.1363 | **0.9881** | +0.1483 |
| switch→host | 1.1607 | **1.0176** | +0.1430 |
| switch→switch | 1.1399 | **0.9926** | +0.1473 |
| **主要量（逐類別差再平均）** | | | **+0.1462** |

✅ **Q 臂三類全部落在註冊的 1.00 ± 0.02 內。** 修正把高報打到 1.000。

### 3-1. base 那一列落在註冊區間之外——而**原因是我的區間訂太窄**

註冊：base = `1.00 + (T−1) ± 0.02` = **[1.093, 1.133]**；實測三類 1.1363 / 1.1607 / 1.1399，**全在上方**。

先查了最可能的儀器解釋，**並排除它**：`measure_loop_period.py` 自己的 docstring 警告
「長週期時 cluster 可能裂開 ⇒ 這個估計會偏低」。若成立，方向剛好對得上。
**但 Q/M 四個臂同時有 in-loop 儀器可以對帳：**

| arm | 外部階梯估計 | **in-loop 實測** | 差 |
|---|---|---|---|
| Q2 | 1143.8 | 1129.9 | +13.9 |
| Q5 | 1109.5 | 1140.5 | −31.0 |
| M3 | 1102.1 | 1076.7 | +25.4 |
| M4 | 1063.1 | 1117.3 | −54.2 |

⇒ 平均帶號差 **−11.5 ms**（外部**略高**，不是偏低）⇒ **偏低假說不成立。**

**真正的解釋**：Q 臂 ratio ＝ 1.000 ⇒ 依定義 base 的 ratio **就是**真實週期。
base ratio 1.1456 ⇒ **隱含週期 1145.6 ms**，而 base 臂的外部 `T` ＝ 1112.9 ⇒ 差 **32.7 ms**。

🔴 **32.7 ms < 本區塊自己量到的臂間差 57.0 ms。** 它在噪聲裡。

⇒ **我註冊的 ±0.02 ＝ ±20 ms 的週期容差，比我自己量到的臂間離散度（57 ms）還窄。**
**區間訂錯了，不是機制多出一塊。**
🔑 教訓：**衍生量的容差，至少要和它所依賴的量的噪聲一樣寬。**

## 4. 工單 M：效應 +0.530 s，落在註冊區間內

| | Q 臂（1 kHz） | M 臂（1 Hz） |
|---|---|---|
| n | 670 | 672 |
| mean | 0.146 s | 0.676 s |
| median | 0.112 s | 0.673 s |
| p95 | 0.382 s | 1.236 s |
| `never` | **0** | **0** |
| 右設限 / 左設限 | 0 / 38 | 0 / 40 |

✅ **效應 ＝ M − Q ＝ +0.530 s，落在 M-quater 註冊的 0.4–0.6 s 內。**

### 4-1. 但**臂層級**的兩個註冊值 miss，原因同 §3-1

M-quater 註冊 1 Hz 臂「平均 0.4–0.6 s、p95 < 1.0 s」。實測 **0.676** 與 **1.236**，兩個都偏高。

**原因**：那個區間訂在**絕對值**上，而絕對值含有一層**兩臂共有的地板**——
1 kHz 臂的 0.146 s（輪詢解析度 ＋ 偵測抖動），**不是重算週期**。
`0.676 − 0.146 = 0.530` ⇒ **效應本身在區間內。**

⇒ 與 §3-1 同一族的錯：**區間要訂在效應上，不是訂在含共同項的絕對值上。**

## 5. 🔴 更正我自己 40 分鐘前註冊的增補 B-3

增補 B-3 寫著「重算迴圈與速率迴圈的週期看起來不是同一個數」，
依據是煙霧臂 `P̂ = 2 × mean = 1147` 對 `T = 1024`。

**那是假影。** 我用了**原始 M 平均**，沒有扣掉 1 kHz 臂的地板。

| 估計法 | 煙霧臂 | 本區塊 |
|---|---|---|
| `2 × 原始 M 平均`（B-3 用的） | 1147 ms | **1352 ms** |
| **`2 × 效應`（扣掉地板）** | **1028 ms** | **1059.8 ms** |
| 同臂的外部 `T` | 1024.2 ms | **1082.6 ms** |
| 差 | **4 ms** | **22.8 ms** |

⇒ 扣掉地板之後，**兩邊都在噪聲內吻合**。

**對增補 B-3 三個假說的判定：**

| 假說 | 預測 | 實測 1059.8 | 判定 |
|---|---|---|---|
| **H-a** 重算週期 ＝ 速率迴圈 `T` | 1083 | 差 23 ms | **未被排除，最接近** |
| **H-b** ＝ `T` ＋ 123 ms 固定量 | 1206 | 差 146 ms | 🔴 **排除** |
| **H-c** 與負載無關的常數 | 1147 | 差 87 ms | 未被排除 |

🔴 **照 B-3 事前寫下的限制，我只能說「H-b 被排除」，不能說「H-a 成立」。**
H-a 與 H-c 差 64 ms，仍在臂噪聲量級。**要分開它們需要第二個工作點，本區塊沒有。**

## 6. 🔑 本輪最強的一件事：**四個沒有共同來源的儀器指向同一個週期**

程式碼 `sleep_for(1s)`，四個儀器量到的實際週期：

| 儀器 | 資料來源 | 估計 |
|---|---|---|
| 外部階梯轉換 | 分身邊值變動的**牆鐘時間戳** | **1107.4 ms**（6 臂） |
| in-loop 儀器 | kernel **自己記的** `measured_interval_s` | **1116.1 ms**（4 臂） |
| ratio 反推 | **veth 位元組** 對分身回報位元組 | **1145.6 ms**（base 2 臂） |
| path 延遲反推 | **每條流第一次拿到路徑的時刻** | **1059.8 ms**（M 2 臂） |

**全距 85.8 ms**，與本區塊量到的臂間離散度（57 ms）同量級。

🔑 這**不是** [[arithmetic-that-fits-is-not-the-mechanism]] 那種「算得出來」：
四條路徑分別經過 HTTP 輪詢、kernel 內部計時、核心網路計數器、與流表寫入時刻，
**若機制是錯的，它們只會各說各話。**

## 7. 本輪的儀器表現

| | 閒置基線 | 六臂範圍 |
|---|---|---|
| 輪詢失敗 | 0 / 600 | **0 / 1571–1903，六臂全 0** |
| gap median | 0.1001 s | 0.1004–0.1017 s |
| gap p95 | 0.1001 s | 0.162–0.278 s |
| gap max | 0.1002 s | 0.359–**4.48 s**（M4） |

M4 有一次 **4.48 s** 的空洞。**逐流記錄的 `gap_before_*` 讓它可以被隔離**：
受影響（自身 gap > 0.5 s）的流 M4 有 17 條、Q5 有 2、B6 有 5，其餘為 0。
**排除它們之後 M4 的平均從 0.6338 變 0.6392（5 ms）** ⇒ **結論不依賴它們。**

📌 這就是為什麼解析度要**逐觀察**記而不是報一個平均輪詢率——
若只報「median 0.1 s」，那 4.48 s 的空洞在報告裡不存在。

## 8. 線性診斷 5:3:1（PREREG §1-bis，**診斷不是門檻**）

| 條件 | 位置間距 | 組內 `T` 差 | 隱含斜率 |
|---|---|---|---|
| base | 5 | +57.0 ms | **+11.4 ms/位置** |
| Q | 3 | +34.2 ms | **+11.4 ms/位置** |
| M | 1 | +39.0 ms | +39.0 ms/位置 |

base 與 Q 的隱含斜率**逐位吻合**（57.0 / 34.2 = 1.6667 = 5/3）。
⚠️ **兩個點的吻合可以是巧合**，而 M 那格（間距 1）帶滿 ±43 ms 噪聲。
註冊的「明顯違反」條件是「M 的組內差最大」——**沒有觸發**（最大的是 base 的 57.0）。

⇒ **與「漂移以線性為主」相容，但一個區塊證不了它。** 照註冊，只在明顯違反時發言，此處不發言。

`t_first_seen` 是分身第一次看見一條新流的時刻。六臂共 **2065 條**流進入統計。
1 kHz 臂的 mean 0.146 s **就是這一段的上界**（其中含 0.1 s 輪詢解析度）
⇒ **偵測延遲本身 < 0.15 s，且不隨 binary 改變**（Q 臂 0.146、base 臂 0.141）。

**只報，不判**（PREREG §5-D：沒有先驗，設區間就是編的）。
