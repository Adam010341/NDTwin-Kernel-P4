NDTwin P4/BMv2 demo. Ubuntu 24.04.4 LTS with the NDTwin Kernel, Ryu, Mininet, OVS, p4c 1.2.5.16 and BMv2 1.15.5-fdd3b893 already built and installed, plus four NDTwin application repositories built and start-tested: Energy-Saving-App, Simulation-Platform-Manager, Traffic-Engineering-App and Network-Traffic-Visualizer. Two of those programs need root and mount NFS at startup, and exit immediately if you run them any other way; systemd units are installed for them but deliberately not enabled, so this image opens no ports until you say so. Read ~/Desktop/README-NDTwin-tools.md before starting anything. Logins: tester/tester (owns the installation, under ~/Desktop/NDTwin-Kernel) and ndtwin/ndtwin; root password ndtwin. Change all three before putting this VM on a network. Git metadata has been removed from every source tree; the commit each one corresponds to is recorded in ~/Desktop/PROVENANCE.txt for the four applications and in ~/Desktop/NDTwin-Kernel/PROVENANCE.txt for the kernel itself.
