NDTwin P4/BMv2 demo. Ubuntu 24.04.4 LTS with the NDTwin Kernel, Ryu, Mininet, OVS, p4c 1.2.5.16 and BMv2 1.15.5-fdd3b893 already built and installed, plus four NDTwin application repositories built and start-tested: Energy-Saving-App, Simulation-Platform-Manager, Traffic-Engineering-App and Network-Traffic-Visualizer. Those four have also been tested against this image's own kernel API, not merely built: all endpoints they call are served except /ndt/disable_switch, which Energy-Saving-App calls and this kernel does not implement -- see ~/Desktop/PROVENANCE.txt for the measurement and its controls. Network-Traffic-Visualizer is a clean checkout of b5e039c, the commit the installation manual pins, because upstream main does not compile; when you build it, take the jar whose manifest has a Main-Class, not the smaller original-*.jar beside it. The kernel tree's doc/ directory (594 files, 20.9 MB of internal engineering audit trail) has been removed from this image, and ~/Desktop/NDTwin-Kernel/PROVENANCE.txt records that removal and lists how this tree differs from the public snapshot at https://github.com/ndtwin-lab/NDTwin-Kernel-P4-public. Two of the six programs need root and mount NFS at startup, and exit immediately if you run them any other way; systemd units are installed for them but deliberately not enabled, so this image opens no ports until you say so. Read ~/Desktop/README-NDTwin-tools.md before starting anything. Logins: tester/tester (owns the installation, under ~/Desktop/NDTwin-Kernel) and ndtwin/ndtwin; root password ndtwin. Change all three before putting this VM on a network. Git metadata has been removed from every source tree; the commit each one corresponds to is recorded in ~/Desktop/PROVENANCE.txt for the four applications and in ~/Desktop/NDTwin-Kernel/PROVENANCE.txt for the kernel itself.
