   - A boot delete of a default is refused.
   - A truthy non-bool `default_action` is refused. The writer is stricter than preflight's truthy check.
   - An unknown `source` raises ValueError.
   - `replay` is treated as `api`.
4. **Refusal precedence.** An owned table with a malformed shape answers 409, not 400, because V7 runs before the builder. An external control plane still wins with its own 409 words (tested).
5. **Package ownership compares `binding.table` to the table's name or alias.** `route_binding.resolve` stores the full name.
